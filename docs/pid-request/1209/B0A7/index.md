Firmware that turns the Elecrow CrowPanel 1.28" rotary display (ESP32-S3) into a helm control knob for boats running a
SignalK server. In its USB mode the knob is a HID device (mouse wheel, media keys and arrow keys) for a chartplotter or PC.
Built on ESP-IDF, espOS, LVGL and TinyUSB.
